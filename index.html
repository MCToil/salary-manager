iPhone と Mac で同期する
給与データをご自身の非公開 Gist に保存し、両方の端末で読み書きします。 経費台帳と同じ方式なので、トークンはあの時のものを使い回せます（保存先の Gist だけ別になります）。
1. GitHub → Settings → Developer settings → Personal access tokens → Tokens (classic) で発行
2. スコープは gist だけにチェック
3. トークンを下に貼って「保存して同期」
4. もう一方の端末では、同じトークンと下に表示される Gist ID を貼る
同期されるのは明細と小項目マスタだけです。API キーとモデル設定は端末ごとに保持され、 Gist には一切送信されません。
トークンもこの端末の localStorage にのみ保存され、GitHub 以外には送信されません。共用の端末では使わないでください。
Anthropic API キー
キーはこの端末の localStorage にのみ保存され、送信先は api.anthropic.com だけです。
